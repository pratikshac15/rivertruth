Numbers from code, words from Nemotron

Every number is computed in code. NVIDIA Nemotron models, served through Meterless Nightshift, only put it into words, and a number guard checks them.

Agents with a shared memory

The agent team writes every explanation, check and finding to the Meterless World Model, with who said it and when, and remembers only what the critic approved.
